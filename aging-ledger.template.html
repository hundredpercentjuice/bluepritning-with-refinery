METHOD

How this was built

Open item
A row in AR.AR_PAYMENT_SCHEDULES_ALL with STATUS = 'OP'. Customer name resolved two hops out — RA_CUSTOMER_TRX_ALL.BILL_TO_CUSTOMER_ID → HZ_CUST_ACCOUNTS → HZ_PARTIES.PARTY_NAME.
Ranking
All __TOTAL_OPEN_ITEMS__ open items ordered by AMOUNT_DUE_REMAINING descending; top 100 taken as the cohort.
Aging
Days past due computed as of __AS_OF__ minus DUE_DATE. This is a balance-method exposure snapshot, not a DSO calculation — AR_RECEIVABLE_APPLICATIONS_ALL links only to already-closed schedules in this dataset, so realized collection speed (__PAID_DSO__ days, cited above) is measured separately, on the paid population only.
Window
Full transaction history, __DATA_WINDOW__. This is a point-in-time register of what's owed as of the run date, not a trailing-window metric.
Revenue cross-ref
"Top revenue customer" tags reference MSI's all-history billed-revenue concentration (__REVENUE_CROSSREF_TEXT__), computed independently from AR.RA_CUSTOMER_TRX_LINES_ALL.
Source
Oracle EBS (Autonomous Data Warehouse), single operating unit (ORG_ID 204). Queried via the TextQL refinery CLI on __AS_OF__.

Meridian Silicon Inc. (MSI) is a fictional-but-production-shaped fabless semiconductor demo estate.
